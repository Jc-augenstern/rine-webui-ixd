# IXD 性能优化 · 2026-09-20

用户在性能分析后授权开始优化。本轮只减少重复计算和刷新，保留 IXD 图形、开场时间轴、相机阻尼、持续呼吸、原模型与完整画质。仅本地源码更新，没有提交、推送或发布。

## 实现

- `src/ixd-mark.ts`：缓存各笔画、箭头、文字与整体缩放的进度；状态相同或成形结束后复用 SVG，倒序拖动和重播仍重新绘制。
- `src/ixd-preview.ts`：缓存节点，阶段、按钮和时间文字仅在显示值改变时更新；暂停、后台与非循环结束时取消 RAF。保留 4.8 秒循环、两位小数时间与高刷新率动画。
- `src/model-viewer.ts`：继续运行原阻尼和交互模拟，以实际 GPU Float32 矩阵及相关材质输入判定是否重绘；载入、输入、主题、尺寸、画质、清晰度、拆解及上下文恢复均使缓存失效。稳定时停止诊断 DOM 写入，动态时约 4Hz；实时计数使用 `window.rhine.stats().viewer`。
- `src/inspection-overlay.ts`、`src/scene.ts`：隐藏解密标记不再读布局或投影。可见时只读取一次视口、准备一次模型矩阵，复用 Vector3 和四个角标节点。
- `src/main.ts`：缓存每帧所需节点，正文显隐、输入隔离及背景遮罩仅在值变化时写入。

未新增帧率限制，没有修改 AO、阴影、折射、模型面数或动画幅度。主场景静帧复用和后台暂停沿用既有实现。

## 浏览器测量

Chromium 153.0.8010.48，1920×1080、DPR 1，每样本约 6 秒。主站使用生产构建，原版保存在本地 `.tools/ixd-perf-baseline-dist` 并由 4174 提供，更新版由 4173 提供；动效独立页通过 Vite 加载原始备份和当前源码。隔离上下文禁用 Service Worker，测试控制页置为空白。

“主线程忙碌度”是 CDP TaskDuration / elapsed，**不是操作系统总 CPU 占用、GPU 时间或整机功耗**。多轮绝对值波动明显，不能据此承诺固定帧率或所有设备的提速比例。

| 第二轮配对测试 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 预览循环主线程忙碌度 | 29.6% | 17.7% |
| 预览循环布局次数 / 6秒 | 1,162 | 648 |
| 查看器静置主线程忙碌度 | 90.7% | 14.7% |
| 查看器诊断 DOM 变更 / 6秒 | 1,446 | 0 |
| 查看器布局次数 / 6秒 | 2,914 | 24 |
| 查看器静置实际绘制 / 复用 | 原实现每次更新都绘制 | 0 / 1,773 |

首轮预览忙碌度为 17.9% → 11.1%，查看器为 35.4% → 9.0%，查看器同样 0 次绘制、1,801 次复用。首轮测试控制页未置为空白，保留原始记录但不作为严格隔离测量。两轮的方向一致；最可靠的收益是消除了确定的重复工作，而非某个绝对百分比。

### 主阵列的实际边界

增加“后、前、前、后”顺序复测，预热和采样均为 6 秒：

| 样本 | 优化后 1 | 优化前 1 | 优化前 2 | 优化后 2 |
| --- | ---: | ---: | ---: | ---: |
| RAF 回调 / 6秒 | 330 | 313 | 760 | 585 |
| 布局次数 | 24 | 647 | 1,540 | 24 |
| 隐藏扫描 SVG 变更 | 0 | 1,878 | 4,560 | 0 |
| 绘制调用 / 渲染帧 | 75 | 75 | 75 | 75 |

隐藏 HUD 的重复工作被稳定消除，但**没有得到稳定的主阵列帧率提升结论**。同版不同轮次的速度差异也很大。完整物理玻璃、阴影、AO、景深和持续呼吸仍然运行，三维持续绘制仍是主要负载；快速切档的多份归位模型峰值本轮未改变。

采样时画质均为比例 1、1920×1080、阴影 2048、AO 32 样本且全分辨率、景深 100%、折射比例 1、超级模式关闭。因呼吸相位和视锥边缘变化，实际可见卡数在 316–317 间变化。原始数据：[ixd-performance-optimized.json](ixd-performance-optimized.json)。配对脚本与原始源码备份留在本地 `.tools/ixd-perf-*`，阵列复测脚本为 `.tools/ixd-archive-repeat.cjs`。

## 画面与行为核验

- SVG 在 2,321 个时间点与原实现状态一致，属性写入从 55,704 次降至 6,680 次；稳定状态连续调用 1,000 次无新增写入。假时钟覆盖暂停、恢复、隐藏、重播、拖动、非循环、慢放及减少动态效果。
- 解密 HUD 对比 14 个时刻并包含倒序跳转，可见几何、透明度及文案一致。隐藏状态 200 次调用为 0 次投影、0 次 DOM 变更。
- 真实网页冻结在应用时码 5.4、7.4、30.5、33.9 秒；扫描线、角标、中心点以及模型和相机坐标与原版一致。隐藏点坐标无需更新，隐藏角标节点由移除改为常驻。
- 1440×900 截图比较，仅隐藏页脚实时时钟：IXD 绘制与身份验证两组像素完全一致；扫描画面 RGB 平均绝对差 0.01661/255、最大差 2；玻璃揭示平均差 0.01100/255、最大差 3，仅 1 个像素的通道差大于 2。没有观察到构图或扫描位置偏移。
- `verification/ixd-preview-check.cjs` 通过：拖动、完整成形、暗色、纯净、手机溢出、暂停、重播、非循环终点、减少动态效果，无运行时错误。
- `verification/ixd-performance-check.cjs` 通过：查看器静帧复用、滚轮、旋转、方向键平移、复位中途接管、拆解、重组、磨砂/清晰、390×844 竖屏、关闭释放模型、暗色重开，无运行时错误。已目视检查手机亮色和桌面暗色截图。
- `verification/ixd-integration-check.cjs` 通过：开场原尺寸与位置、IXD 成形、欢迎页、正常点击启动、跳过、重播复位和手机边界，无运行时错误。
- 查看器使用真实 Three.js 矩阵的模拟检查通过：720 次稳定更新只绘制 1 次，相机、材质、纹理、投影变化均触发重绘。两轮独立代码审查未发现当前功能所需渲染输入遗漏。
