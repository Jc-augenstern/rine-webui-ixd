## 银河状态与预算

普通画质的模拟网格 **192×116**，低画质/小屏 **128×78**。CPU typed-array 双缓冲分别保存 `velocity.xy` 与输运位移 `material.zw`，以固定 1/60 秒推进、反向采样前一状态；速度与物质状态均真实跨帧保留。最后只上传低分辨率数据纹理（普通一次 356,352 字节），没有每帧高分辨率银河重绘或 GPU 回读。高分辨率 1280×768 云带 atlas 只生成一次，每帧从原图按动态物质坐标取样，避免反复采样累积模糊。

输入使用实际渲染容器 rect 和 CSS 像素。屏幕经 cover、视差和焦点变换映射至银河物质平面；Y 方向与 shader 一致。实际指针路径有界队列只消费一次，长段分摊采样冲量。影响半径 190 CSS px，流速上限 210 CSS px/s，云位移上限 115 px；速度阻尼 2.65/s，构图恢复 1.05/s。2600 个已有星尘按银河密度初始化，不重复叠加原 atlas 的亮星；每个保留 velocity/offset/baseline，不靠鼠标新生成星尘。

停止没有新冲量；leave、blur、hidden 清输入并保留已模拟运动。详情/设置禁强输入。reduced 模式清除旧模拟状态并静态显示；普通低画质保留运动，降低网格与显示数量；WebGL 不可用/上下文丢失时保留可导航的静态银河且停止无用 CPU 模拟。几何、纹理和监听均随实例释放。统一帧循环、同一个 Three renderer；正常背景为四个 draw call、两张纹理。

1920×1080、指针全幅 X 的几何位移量约为远星 5.84px、云带 8.84px、中景星 38.2px、近星 65.5px；这是代码参数换算值，不是所有设备的感知或帧率保证。
