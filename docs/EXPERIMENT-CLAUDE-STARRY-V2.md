> 本分支已移除 v1 的 `src/ixd-observatory.css`，`docs/EXPERIMENT-CLAUDE-REDESIGN.md` 仅作为 v1 历史说明保留。

## 设计方向：深空漫游 · 星门

不再使用刻度尺、准星角标、菱形切角或“仪器透镜”。整站统一成一次深空航行的视觉语言：

- **光**：暖星光金（`#ffd9a6 / #fff1dc`）为主导强调，极光青（`#7ae8d9`）表示“在线 / 成功”，
  星云紫（`#b7a4ff`）只作为环境光；错误为柔和的“日食”玫红。
- **形**：轨道与光晕。按钮、标签、页签、分页、页眉页脚是胶囊；面板是圆角“星窗”；
  分隔线是一段渐隐的星光弧；列表每行是一颗小星卡。
- **动**：星体诞生、星门光圈打开、星窗漂入。减少动态效果时全部改为直接到位。

## 可访问性与性能

- `prefers-reduced-motion` 与 `.sm-root[data-reduced="true"]` 关闭星尘漂移、光环旋转与星窗位移；星门走原有的短淡入路径。
- `data-page-hidden="true"` 暂停所有 CSS 动画；`data-terminal-motion-paused` 同时暂停登录面板的星。
- 触屏不保留粘滞 hover；≤760px 隐藏星点轨道光环避免遮挡。
- 没有新增 rAF 循环、粒子或绘制调用。
