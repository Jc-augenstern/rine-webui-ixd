## 原有银河中的路径尾流

复用现有 `GalaxyInteraction` 持续速度／物质位移场和同一个 GPU 纹理。新增 CPU 历史量（能量、能量×年龄、能量×初生宽度、侧向剪切）随相同速度输运，不建立第二套渲染模拟，不添加烟雾或模糊覆盖图。

真实 PointerEvent 时间戳和合并事件组成连续轨迹段；每段记录切线、出生速度、初始宽度及已消费时间。固定 1/60 s 积分按时间交集消费每段，每段冲量只注入一次，采样沿弧长补齐，避免快划时串珠。输入与轨迹各固定 512 项；完成段仅保留 24 项调试历史。

速度用约 55 ms 连续平滑，120–1100 CSS px/s 对应约 80–36 CSS px 初生能量带宽，另设至少三个网格的可靠下限。不使用 `1/speed`；低于真实微小移动阈值不持续注入，停止不会生成最大的圆形笔刷。每段保留自己的出生宽度和方向，不因最新速度改写整条旧路径。

约 55 ms 后逐步加强沿轨迹法线的扩散，切向更收束；连续空间相关、固定相位的噪声将扩散率调制在基准的 ±18% 内，边缘剪切也平滑变化。局部年龄和能量随流场运动，旧区域自然卷动、展开和阻尼。云带仍采样原 atlas，已有星点共享同一位移场，交互节点及文字不参加输运。

全局速度上限 210 CSS px/s、物质位移上限 115 CSS px，输入停止或移出不清掉既有速度。失焦／隐藏清掉输入基线并限制恢复步长；细节弹窗停用新输入；低画质重采样已有状态，减少动态效果关闭强交互。
