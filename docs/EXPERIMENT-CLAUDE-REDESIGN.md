# EXPERIMENT — Claude 前端重设计（非正式规范）

> 状态：**实验性**。仅存在于分支 `experiment/ixd-external-model-v1`，不代表 IXD 正式设计规范，
> 不应合并回任何原分支，也不替代 `DESIGN.md` / `IXD_SPEC` 等永久文档。

## 设计方向：夜间天文台仪器（Observatory Instrument）

保留 IXD 原有的深空冷色、蓝紫强调色 `#a3a2ff`、细线终端语言，在此基础上统一为一种“观测仪器”视觉：

- **刻度尺母题**：把竞赛时间轴已有的刻度语言扩展为全站共享的分隔方式（页眉页脚、终端左缘、分区、标签页、分页、Markdown 分隔线）。
- **准星对焦**：星点 hover / 键盘聚焦时出现四角准星锁定；按钮与面板四角使用同一套角标。
- **透镜面板**：详情终端为带模糊背景的玻璃透镜，从中线展开，顶部光线扫过表示“就绪”。
- **实时指针光**：星图背景的柔光跟随 `StarMapUI.update()` 中已有的缓动指针（与星点视差同一帧写入），减少动态效果时关闭。
- **观测日志列表**：列表条目自动编号，hover/focus 时左侧指示线展开、编号变暖色。
- **三种明确状态**：加载（旋转环 + 扫描线）、空（虚线星环）、错误（菱形警示 + 洋红左边），不再只靠文字区分。
- **表单**：暗色井槽 + 从左绘出的聚焦线；自定义复选框、下拉箭头、文件选择按钮。
- **登录**：身份接入面板加刻度顶边、双色准星角、提交按钮光带与字距动效；加载进度加旋转环。

## 实现范围

- 新增 `src/ixd-observatory.css`（最后加载的覆盖层，只改表现）。
- `src/ixd-experience.ts`：仅新增一行 CSS import。
- `src/ui/star-map-ui.ts`：在已有指针缓动处写入两个 CSS 变量 `--sm-px/--sm-py`，不改行为。
- 未改动：文案、路由、数据、admin、server、shared、数据库、迁移、认证、权限、调色板数值（`check:palette` 仍通过）。

## 可访问性与性能

- `prefers-reduced-motion` 与 `.sm-root[data-reduced="true"]` 下关闭动画、指针光、终端裁切展开。
- `data-page-hidden="true"` 时暂停所有 CSS 动画。
- 触屏（`hover: none`）不保留粘滞 hover 效果；≤760px 隐藏星点准星避免遮挡。
- 指针变量只在指针实际移动时写入，不新增 rAF 循环。
