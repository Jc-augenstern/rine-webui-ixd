# IXD 管理后台操作指南

后台与星图前台共用真实 API、会话和 PostgreSQL，但使用独立页面与构建。开发入口为 `http://127.0.0.1:5174/admin/`，正式部署入口为同域 `/admin/`。后台不加载星图、音频或开场动画。

## 登录与权限

先按 [LOCAL_SETUP.md](LOCAL_SETUP.md) 启动服务。开发账号由 `npm run db:seed` 创建，用户名、邮箱、随机密码在本机 `.local/development-accounts.json` 的 `accounts` 数组中；选择 `ADMIN` 项登录。不要将此文件提交或公开。旧前端 Demo 凭据不能绕过真实认证。

普通 `USER` 登录后台会明确显示无管理权限。`EDITOR` 只看到已授权类型或管理项目的入口，具体资源和每次读写仍由 API 校验。`ADMIN` 管理所有内容、用户、站点设置和审计。兴趣方向、社团成员身份、后台角色是三个不同概念；选择兴趣方向不会自动授予后台权限。

忘记密码可在登录页提交邮箱；开发环境到本地测试收件箱取重置邮件。正式首次管理员使用 `npm run admin:init`，失去管理员访问时使用 `npm run admin:recover`，需要服务器命令行权限。具体参数和生产前置条件见 [DEPLOYMENT.md](DEPLOYMENT.md)。不要直接修改数据库密码字段。

全新库的管理员初始化会建立默认站点节点设置。管理员可再执行受控 `npm run content:import -- --username YOUR_ADMIN` 导入六方向、社团介绍和加入说明初稿；重复执行不会覆盖运营修改，也不会创建开发账号或示例活动。正式运营前请在后台核实初稿的联系渠道和实际安排。

## 创建、修改与发布内容

1. 打开相应菜单，使用搜索、状态、方向、排序及分页定位内容；也可点击「新建」。
2. 填写标题、摘要、Markdown 正文、可见范围、适合方向、置顶、重要程度、排序和标签。公开、登录用户、社团成员三种可见范围由服务端判断。
3. 「保存草稿」只保存编辑版本。已有公开内容在再次发布前继续显示上一次已发布版本。
4. 「预览草稿」通过服务器的安全 Markdown 渲染查看；「查看已发布版本」用于对照实际公开正文。
5. 点击「发布」并确认，前台重新读取内容时即可看到，无需修改源码或重新构建。若设置定时发布时间，则点击「保存定时发布」，到时由服务器发布。有效期结束后不再公开。
6. 「撤回」隐藏公开内容；「归档」结束内容运营；「删除」是危险操作，需要确认，有业务或历史引用时服务器会拒绝。

公告的「这是重要更新」会重新提醒并使旧阅读记录显示未读，普通错字修改请勿勾选。通知取决于用户与内容的实际关联和权限，不会向无权限用户泄露正文。

有未保存修改时，站内切换和关闭页面会提示。多人同时编辑遇到版本冲突（409）时，当前输入会保留；先复制仍需保留的修改，再选择「重新读取服务器版本」，比较后重新编辑。不要用反复点击保存覆盖他人更新。

## 各类型专属字段

| 菜单 | 实际可编辑信息 |
| --- | --- |
| 公告中心 | 通用正文、重要程度、方向、置顶、附件与生命周期 |
| 赛事中心 | 届次、年份、组织者、资格、赛道、官网/报名/来源链接、最后核实时间、报名开始/结束、内部与提交截止 |
| 项目广场 | 负责人、阶段、招募开关、申请截止、展示链接；逐项添加岗位、描述、名额、启用状态和顺序 |
| 活动与沙龙 | 开始/结束、时区、线下地点、线上链接、报名窗口、取消截止、名额、报名开关、活动状态、回顾和资料 |
| 学习资源 | 难度、资源类型、外链、来源、授权说明 |
| 作品与成果 | 作者姓名及可选用户关联、关联项目、展示图片、演示链接；逐项填写奖项和依据链接 |
| 六方向介绍 | 固定方向键、关键词、学习建议、关联内容 |
| 学习路线 | 难度；逐项添加步骤标题、正文、关联资源和顺序 |
| 社团介绍与加入说明 | 选择「关于社团」或「加入说明」并维护正文 |

赛事每个时间分别选择「未知」「仅日期」或「具体时刻」。未知时间保持空值；只知道日期时不要编造截止小时。日期和具体时刻可保留来源时区；输入具体时刻的控件注明北京时间（UTC+8），服务器保存带时区时间。

## 上传、选择与替换附件

内容编辑器可直接上传或从媒体库选择封面、图片和附件，也可取消当前引用并选新文件。支持 PNG、JPEG、WebP、静态 PDF、UTF-8 TXT，每个文件最多 10 MB；文件格式、真实内容及权限由服务器验证。

`PUBLIC` 附件仍须被当前可见的公开内容引用才能匿名下载；`PRIVATE` 附件受账号与内容权限保护。上传成功不等于公开。媒体库可搜索、筛选、查看引用记录。草稿、公开版本或历史版本仍在引用的附件无法直接删除；替换文件不会破坏旧版本引用。

## 申请、成员、报名与作品审核

「项目申请与成员」可搜索和筛选真实申请，点击「查看 / 审批」阅读意向说明与作品链接，填写处理理由，再「批准并加入项目」或「拒绝申请」。批准在服务端事务中检查岗位、名额与重复成员，结果通知申请人。冲突时保留处理输入并刷新查看最新状态。

「项目成员」列出已加入者，可「记录退出」或「移除成员」，需确认，并释放对应岗位名额。请先联系成员确认业务情况；后台不执行未经授权的外部消息发送。

「活动报名管理」查询报名和取消状态，点击「管理活动」进入活动编辑。活动取消或时间地点重要变更请保存并发布，让服务器通知已报名者。本版本没有签到功能。

「作品与成果」筛选「待审核」查看用户投稿，可以发布通过审核的作品，或选择「退回作者修改」并填写原因。作者在个人中心查看结果和退回说明。

## 用户、授权和站点设置

「用户与授权」支持用户名、显示名、邮箱搜索，以及角色、状态、兴趣方向筛选。点击「管理」查看必要资料、申请与报名关联，再维护后台角色、账号状态和社团成员身份。保存账号状态和保存编辑授权是两个独立操作。

给 `EDITOR` 添加授权时，指定内容类型、可选方向/具体资源，再勾选允许操作。方向和资源均留空表示该类型全范围，仍受勾选操作限制；只授予实际所需权限。保存授权会撤销旧会话，用户需重新登录。停用账号或「撤销全部会话」同样立即限制旧会话。最后一个有效管理员有服务器保护。

「站点设置」维护菜单、节点和站点展示配置，同样先保存草稿再发布。不要把秘密、密码或个人敏感资料写进公开站点配置。重大操作可在「操作日志」查到操作者、资源、时间与变更摘要，日志不包含明文密码或令牌。

后台页面出现 API 不可用时应检查 `.local/logs/` 和健康检查地址；错误不会转为假成功或静态 Mock。部署、备份和恢复分别见 [DEPLOYMENT.md](DEPLOYMENT.md) 与 [BACKUP_RESTORE.md](BACKUP_RESTORE.md)。
