# IXD 星图与赛事界面改造

2026-09-28。本轮基于 `feat/ixd-platform-v1` 的 `861dedd`，范围为前台图标、CORE 分层空间、赛事时间展示与一级星图悬浮提示。API、后台、共享契约、数据库及运营内容保持原样。

## 一级主星

| 栏目 | 图形语义 | 动效 |
| --- | --- | --- |
| 赛事中心 | 24 格轨道钟盘与时间信标 | 刻度顺序提亮、局部扫线、核心微脉冲 |
| 项目广场 | 三个拼接模块连接协作中枢 | 链路能量流、模块错峰点亮 |
| 活动与沙龙 | 四点聚合场域与回响中心 | 双层回响、节点轻微呼吸 |
| 学习中心 | 四阶知识路径与支路 | 递进线流、分层节点点亮 |
| 作品与成果 | 展示角框、成果核与记录轨道 | 框边扫线、记录轨光点 |
| IXD CORE | 原 IXD 品牌与外围六点中枢 | 克制轨迹、核心明暗呼吸，无整体旋转 |

公告中心沿用当前运营配置的 `echo-nebula`；公告、六个方向、个人中心的原图形函数保持不变。一级默认预设映射到新的栏目语义，运营明确选择其他预设时仍使用所选造型；学习兼容运营默认 `neural-cluster` 与原静态默认 `lattice-satellites`。所有图形保留视觉种子、同一 SVG 实例、hover/选中反馈，以及减少动态效果与页面隐藏暂停行为。

`star-map-ui.ts` 的 `starMarkup()` 不再为一级主星生成“探索社团节点”浮层。原名称、方向星已有辅助提示、点击命中区域和发光样式保留。

## CORE 的空间与层级

社团介绍只保留“进入方向二级星图”主要按钮，删除六方向文字捷径。

```text
一级星图 → CORE 详情 → 六方向星系 → 方向详情
一级星图 ← CORE 详情 ← 六方向星系 ← 方向详情
```

进入使用应用原有帧时钟驱动约 1.9 秒的统一进度：当前 CORE 的同一 SVG 从详情位置移向视野中心、持续放大至覆盖视野，随后内部星系从屏幕中心缩放展开。退出反向读取同一进度曲线，先收回内部星系，再恢复 CORE 详情；再次关闭详情才返回一级星图。

六方向共用原银河 renderer 与节点交互，新增固定的小型星系布局、轻淡双臂、星尘及中枢标记。节点不公转，二级图隐藏一级栏目直达按钮，只提供返回 CORE。方向详情仍使用原节点到详情的连续往返。

动画支持途中 Esc 反向、重复操作、窗口变化、浏览器历史与方向深链接。读取 CORE 的准备阶段也可取消，过期响应不改变新路由。返回 CORE 时重新读取 API，避免缓存旧的私人正文；逆向终点直接保持主图文字隐藏，消除从主图再次退暗的闪现。隐藏/重播清理转场并归还原 SVG。减少动态效果模式直接完成状态交接。

## 赛事时间标尺

保留 `q / direction / phase / sort / year` 与原表单提交、分页、详情路由。桌面筛选改为紧凑两行；在同一 1440×900 视口、约 590px 正文宽度下，从 256px 降为 145px。手机保持两列与 16px 输入字号。

赛事名称可点击；下方为细线标尺、41 个长短刻度、当前指针、开始与截止端点、状态及剩余时间。详情保留原完整正文、日期、来源、正式报名链接、收藏和内部参赛意向，并复用标尺。

- 两端均为具体时刻：使用真实时间差计算位置，以各自 IANA 时区展示端点；剩余时间精确到分钟。
- 两端均为同一时区的日期：指针落在当前日历日单元，不把日期伪装成午夜截止；截止当天显示“今日截止 · 时刻待公布”。夏令时不会令日历进度提前跳日。
- 缺失、未知、无效、顺序矛盾、精度混合或日期时区不同：显示“待公布 / 待核实”，无填充与指针，不制造倒计时。
- 沿用现有 60 秒及窗口焦点刷新。聚焦筛选表单时也只更新标尺，保留输入与焦点；不添加逐秒定时器或写入数据库。

## 文件与继续开发

- `src/ui/galaxy-glyph.ts`、`galaxy-glyph.css`：六主星语义及局部动画。
- `src/ui/core-system.ts`、`core-system.css`：二级星系固定布局、环境与转场样式。
- `src/ui/star-map-ui.ts`：同一 SVG 转场、返回、焦点、取消与悬浮层。
- `src/platform/platform-ui.ts`：分层路由、真实内容读取及赛事接线。
- `src/platform/competition-view.ts`、`competition-view.css`：日期模型、筛选、标尺、列表。
- `scripts/check-competition-time.mjs`：日期边界、时区、夏令时与未知数据回归。
- `docs/CURRENT_STATE.md`、`docs/IXD_SPEC.md`、本报告：当前状态、用户确认的 CORE 层级原则及交付说明。

修改位置或图形时先保持同一 SVG 往返；不要新增第二套银河 renderer。日期显示必须继续服从现有 `DateValue` 精度，不修改后台数据来掩盖缺失信息。

## 本地使用

在仓库根目录执行 `npm run platform:start` 可启动完整已有环境；API 已运行时，`npm run dev` 单独启动前台。浏览器使用 `http://127.0.0.1:5173/`。通过开场后的“访客浏览”进入公开星图即可验证本轮功能。

```powershell
npm run check:auth
node --experimental-strip-types --test scripts/check-competition-time.mjs
npm run build
```

前台生产目录为 `dist/`。实际平台使用真实账号；随机开发凭据仍仅保存在本机 `.local/development-accounts.json`，见 [LOCAL_SETUP](LOCAL_SETUP.md)。本轮不更改账号或恢复旧 Demo 旁路。
